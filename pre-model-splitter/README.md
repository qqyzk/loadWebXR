# 🎯 3D模型分割工具

一个专业的3D模型分割工具，支持GLB/GLTF格式，提供两种智能分割策略。

## ✨ 特性

- **空间分割**: 按坐标轴范围分割，保持空间连续性
- **数量分割**: 按三角形和顶点数量分割，优化渲染性能
- **批量下载**: 一键下载所有分割后的模型文件
- **拖拽上传**: 支持拖拽文件到页面
- **实时预览**: 显示模型信息和分割结果

## 🚀 使用方法

1. 打开 `index.html`
2. 选择或拖拽GLB/GLTF文件
3. 选择分割策略
4. 设置分割参数
5. 点击"开始分割"
6. 批量下载分割结果

## 📁 项目结构

```
model-splitter/
├── index.html          # 主程序（模型分割工具）
├── input/              # 输入文件夹（存放待分割的模型）
├── output/             # 输出文件夹（存放分割后的模型）

```

## 🛠️ 技术栈

- **Three.js**: 3D模型处理
- **GLTFExporter**: 模型导出
- **ES6模块**: 现代JavaScript
- **CSS Grid**: 响应式布局

## 📝 分割策略说明

### 空间分割
- 按X/Y/Z轴范围分割
- 适合大型环境模型
- 保持空间连续性

### 数量分割  
- 按三角形和顶点数量分割
- 优化渲染性能
- 控制单个块大小
